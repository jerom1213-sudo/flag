# 서구청 업무계획 자동 수집 서버

기존 깃발 통합관리 프로그램과 분리한 공개 업무계획 PDF 수집 서비스.

- 공식 `www.seogu.gwangju.kr`의 주요업무계획 게시물/첨부파일만 허용함.
- 공개 게시물의 세션과 Referer를 이어서 정상 다운로드함. TLS 인증서 검증을 유지함.
- POST `/download`는 서버 간 토큰 인증 후 원본 PDF 바이트, 원본 URL, SHA256, 조회시각을 반환함.
- GET `/health`는 서비스 실행 상태만 표시하며 원본 다운로드 성공을 뜻하지 않음.
- 10MB 제한, 동시 두 요청, 15분 메모리 캐시를 적용함. 실패 결과와 사용자 자료는 저장하지 않음.
- `COLLECTOR_TOKEN`(24자 이상)을 서버 환경변수로 설정하여 `node server.mjs`로 실행함.
- Render 무료 웹 서비스, Singapore 리전, 이 브랜치의 `collector` 디렉터리로 배포 가능함.

행사레이더 서버의 `PLAN_COLLECTOR_URL`과 `PLAN_COLLECTOR_TOKEN`을 배포된 서비스에 맞춰 설정하면 직접 다운로드 실패 시 이 서버가 원본을 자동 수집하고 행사레이더가 PDF를 분석함.

다른 실행 환경에서 원본 연결을 검증하기 위한 대안이며, 배포 후 실제 서구청 PDF 수신과 행사 분석을 확인하기 전에는 해결 완료로 간주하지 않음.
