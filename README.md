# 더 플래그 통합관리 프로토타입

깃발 제작, 보관, 배송, 설치, 회수를 한 화면에서 관리하는 브라우저 기반 프로토타입입니다.

## 실행

보안을 위해 데이터는 브라우저 저장소가 아니라 서버의 `db/data.json`에 저장됩니다.

```bash
node server.js
```

실행 후 브라우저에서 `http://localhost:4173/`로 접속합니다.

## 기본 계정

| 역할 | 아이디 | 비밀번호 |
| --- | --- | --- |
| 본사 관리자 | `admin` | `1234` |
| 배송 기사 | `driver1` | `1234` |
| 고객사 | `client01` | `client01` |

## 구현 범위

- 역할별 화면 분리: 본사 관리자, 배송 기사, 고객사
- 근조기/축하기 주문 접수 및 주문번호 자동 채번
- 근조기 2시간 SLA, 21시 이후 익일 처리, 축하기 행사 시작 전 SLA
- 미배정 주문 기사 자율 배정 및 관리자 강제 배정
- 설치완료 사진 기록, 근조기 상주현황판 사진 필수 입력
- 재사용 깃발 회수완료 시 고객사 보관 재고 복귀
- 지점 재고, 고객사별 깃발 수량, 행사장 위치 추적
- 고객사/기사/행사장/깃발 관리와 변경이력(TR) 기록
- 활동 기사 대상 문자/카카오톡 알림 시뮬레이션 로그
- 서버 DB 파일 저장

## 참고

데이터는 `db/data.json`에 저장되며, 이 폴더는 `.gitignore`로 제외했습니다. 실제 운영 전에는 SQLite/PostgreSQL 전환, 비밀번호 해시, 접근 권한 검증, HTTPS 적용이 필요합니다.
